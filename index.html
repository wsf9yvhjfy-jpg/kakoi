    操作のヒント

    囲い塗り

    L
    囲い塗りツール。ドラッグで囲んだ形がそのまま塗られます
    1〜5
    形の切り替え（自由・多角形・矩形・楕円・扇）
    X
    塗る／削るの切り替え
    G
    単色／グラデーションの切り替え
    多角形
    押すたびに頂点。始点を押す・ダブルクリック・Enter で確定、Esc で中止
    Shift
    矩形・楕円を正方形・正円に。グラデーションの線は 45° 刻み

    描く・直す

    B / E
    ブラシ／消しゴム（ブラシの「混ぜる」で混色）
    W
    ゆがみ（押す・縮める・膨らます・渦）
    V
    移動・変形。Enter で確定、Esc で取り消し、矢印キーで 1px 移動
    I・Option
    スポイト。Option（Alt）を押している間もスポイトになります
    Shift+X
    メイン色とサブ色を入れ替え
    [ と ]
    ブラシ・消しゴム・ゆがみの大きさ
    ⌘Z・Ctrl+Z
    取り消し（2本指タップでも取り消せます）。⇧⌘Z・Ctrl+Y でやり直し

    ラインブレンド・色

    J
    ラインブレンド。色の違うところをまたいで直線を引くと、両端の色を拾ってグラデーションでつなぎます（Shift で 45° 刻み）
    色の選び方
    「色」の右上で 四角・ホイール・色相×明るさ を切り替えます
    スウォッチ
    「＋」で今の色を登録。Option＋クリック・右クリック・長押しで外します。「⋯」からリストの追加・切り替え、Photoshop 用（.ase・.aco）や Krita・GIMP 用（.gpl）の書き出し・読み込みができます

    アニメーション

    ← / →
    前・次のコマ。Option を押しながらで前・次の絵へ
    Enter
    再生・停止
    N / Shift+N
    このコマに白紙の絵を作る／直前の絵を複製する
    O
    オニオンスキンの表示・非表示
    自動コマ
    絵のないコマで描くと、そのコマに新しい絵を自動で作ります。消しゴム・ゆがみ・移動は、直前の絵を複製してから直します。背景など動かないレイヤーは、レイヤーの「アニメーションするレイヤー」をオフにすると、最初の絵に描き足されます
    再生
    タイムラインの「再生」でループ・往復・1回を選び、「範囲」で再生するコマを絞れます
    しくみ
    各レイヤーの絵は、次の絵があるコマまで続けて表示されます（コマ打ちは絵の間隔で決まります）

    ウィンドウ

    見出しをドラッグ
    色・ツール設定・レイヤー・タイムラインをウィンドウとして切り離し、好きな場所に置けます。ツールの列とタイムラインは点々をドラッグします
    ドッキング
    ドラッグ中にほかのウィンドウの上下の端に重ねると縦に、左右の端に重ねると横に並んでくっつきます（青い線が出た位置）。右のパネルや画面の下（タイムライン）・左端（ツール）に重ねると元の場所に戻ります。まとまったウィンドウは上の細い点々でまとめて動かせ、間の境目で幅を変えられます
    Tab
    パネルを一時的に隠して、画面を広く使います
    ウィンドウ
    上のメニューで表示・非表示、すべて切り離す、配置を元に戻す

    表示

    Z
    ズームツール。クリックで拡大、Option＋クリックで縮小、左右ドラッグで連続ズーム
    ⌘＋ / ⌘−
    拡大・縮小。⌘0 で全体表示、⌘1 で 100%
    R＋ドラッグ
    キャンバスを回転（Shift で 15° 刻み）。Shift+R で 0° に戻す。2本指のひねりでも回せます
    H
    表示を左右反転（形の狂いの確認に）
    移動
    スペース＋ドラッグ、中ボタン、スクロール、2本指ドラッグ
    ペン
    Apple Pencil などのペンを使うと、以降は指が移動・拡大専用になります

    ファイル

    ⌘S
    保存（KAKOI 形式）。2回目からは同じファイルに上書きします。⇧⌘S で別名で保存
    ⌘O
    KAKOI、PSD、ZIP、PNG・JPEG・WebP を開きます。キャンバスへのドラッグ＆ドロップでも開けます
    ⌘E
    PSDで書き出し（レイヤーつき）。⇧⌘E で PNG

    保存先を選ぶ画面は、Chrome・Edge でこのファイルを直接開いたときに出ます。Claude の画面の中では、ブラウザのダウンロードとして保存されます（そのため KAKOI は .kakoi.zip、PSD は ZIP に入った形になります）。作業中の絵はこのブラウザにも自動保存されます。

    合成した絵は、いま表示しているレイヤーを重ねたものです。透明な背景にしたいときは「背景」レイヤーを非表示にしてください。Chrome・Edge で直接開いているときは保存先のフォルダを選べます。それ以外は ZIP にまとめて保存します。
